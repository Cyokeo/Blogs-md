## 源码
```c
// sel4test/kernel/include/kernel/thread.h
```
这段代码是**实时操作系统（如 seL4）中经典的两层位图优先级队列实现**，核心思路是用**两级 64bit 位图（Bitmap）压缩存储优先级状态**，并结合 CPU 指令集（`clzl`）以**O (1) 时间复杂度**快速获取最高优先级。

### 一、核心数据结构设计

代码依赖两个关键的位图数组（隐藏在 `NODE_STATE` 宏中）：
1. **`ksReadyQueuesL1Bitmap[dom]`**：
    第一层（L1）64bit 位图，每个位代表**一组优先级**是否有就绪任务。
    - 若某一位为 `1`，表示对应的 L2 组中至少有一个任务就绪。
2. **`ksReadyQueuesL2Bitmap[dom][l1index_inverted]`**：
    第二层（L2）64bit 位图数组，每个元素对应 L1 中的一个组。
    - 每个 L2 位图的每一位代表**一个具体优先级**是否有就绪任务
#### 优先级数量扩展
由于是两层 64bit 位图，总支持的优先级数量为:
`64（L1 组数） × 64（L2 每组优先级数） = 4096 个优先级`
