## 3. **模板特化的匹配规则**

`simple_completion_signature` 的模板特化模式是 `R(Args...)`，这里：
- `R` 匹配**返回类型**
- `Args...` 匹配**参数类型列表**
```cpp
template <typename R, typename... Args>
struct simple_completion_signature<R(Args...) &>
{
  typedef R type(Args...);
};

// 当传入 void(int)& 时：
// R = void
// Args... = int
// type = void(int)
```

## 5. **验证示例**
```cpp
#include <iostream>
#include <type_traits>

template<typename> struct Test;

template<typename R, typename... Args>
struct Test<R(Args...)> {
    static void print() {
        std::cout << "Return type: " << typeid(R).name() << std::endl;
        std::cout << "Has " << sizeof...(Args) << " parameters" << std::endl;
    }
};

int main() {
    // 传入的是 void(int, double) 这个完整类型
    // 不是 [void, int, double] 三个参数
    Test<void(int, double)>::print();
    // 输出：
    // Return type: void
    // Has 2 parameters
    
    return 0;
}
```

## 6. **在 async_result 中的实际使用**
```cpp
// 示例1：单个签名
async_result<Token, void(error_code, size_t)>
// Signatures... = void(error_code, size_t) 一个元素

// 示例2：多个签名（用于支持多种完成方式）
async_result<Token, 
  void(error_code, size_t),      // 成功完成
  void(error_code)               // 错误完成
>
// Signatures... = void(error_code, size_t), void(error_code) 两个元素

// 示例3：带引用限定符
async_result<Token, void(int)&, void(int)&&>
// Signatures... = void(int)&, void(int)&& 两个元素
```

## 8. **为什么这样设计？**

### 8.1 **函数类型作为一等公民**
```cpp
// C++ 中函数类型是完整的类型
using FuncType1 = void(int);
using FuncType2 = int(double, char);

// 可以作为模板参数传递
template<typename T>
struct Processor;

Processor<FuncType1> p1;  // 处理 void(int)
Processor<FuncType2> p2;  // 处理 int(double, char)
```

### 8.2 **支持多种完成方式**
```cpp
// Asio 的异步操作可能有多种完成方式：
// 例如 async_read_some 可能：
// 1. 成功：void(error_code, size_t)
// 2. 错误：void(error_code)

// async_result 需要支持所有可能的签名
async_result<Token, 
  void(error_code, size_t),  // 正常完成
  void(error_code)           // 错误完成
>
```

## 总结
**关键点**：
1. **Signatures 是函数类型列表**，不是返回类型列表
2. **每个 Signature 是一个完整的函数类型**，如 `void(int)`、`int(double, char)` 等
3. **simple_completion_signature 接收完整函数类型**，处理后再输出完整函数类型
4. **模板参数 `R(Args...)` 是模式匹配**，`R` 匹配返回类型，`Args...` 匹配参数类型
