
c11 引入的新特性

## 基本语法

```
// 传统语法
ReturnType functionName(Parameters);

// 尾随返回类型语法  
auto functionName(Parameters) -> ReturnType;
```

## 具体示例

### 传统方式 vs 尾随返回类型

```
#include <iostream>
#include <vector>

// 传统声明方式
int add(int a, int b) {
    return a + b;
}

// 尾随返回类型方式
auto multiply(int a, int b) -> int {
    return a * b;
}

// 更复杂的例子
class MyClass {
public:
// 传统方式
std::vector<int> getData() {
    return {1, 2, 3};
}

// 尾随返回类型方式
auto getMoreData() -> std::vector<int> {
    return {4, 5, 6};
}
};
```

## 尾随返回类型的主要优势

### 1. 解决依赖参数的返回类型

这是最重要的应用场景：

```
#include <vector>
#include <type_traits>

template<typename T, typename U>
auto add(const T& a, const U& b) -> decltype(a + b) {
    return a + b;
}

int main() {
    auto result1 = add(1, 2);        // int
    auto result2 = add(1, 2.5);      // double
    auto result3 = add(1.5f, 2.5);   // double
}
```

### 2. 在 SFINAE 中的应用

```
#include <iostream>
#include <type_traits>

// 检查类型是否有 size() 方法
template<typename T>
auto has_size_method(const T& obj) -> decltype(obj.size(), std::true_type{}) {
    return std::true_type{};
}

auto has_size_method(...) -> std::false_type {
    return std::false_type{};
}

// 使用示例
template<typename Container>
auto process(Container& c) -> decltype(has_size_method(c)) {
    if constexpr (decltype(has_size_method(c))::value) {
        std::cout << "Container size: " << c.size() << std::endl;
        return std::true_type{};
    } else {
        std::cout << "No size method" << std::endl;
        return std::false_type{};
    }
}
```

### 3. 处理复杂类型

```
#include <vector>
#include <map>
#include <string>

// 返回复杂类型时更清晰
auto createComplexData() -> std::map<std::string, std::vector<int>> {
    return {
        {"even", {2, 4, 6, 8}},
        {"odd", {1, 3, 5, 7}}
        };
}

// 相比传统方式，可读性更好：
// std::map<std::string, std::vector<int>> createComplexData() { ... }
```

### 4. Lambda 表达式的自然语法

cpp

```
#include <functional>

int main() {
    // Lambda 表达式使用类似的语法
    auto lambda = [](int a, int b) -> int {
        return a + b;
    };

    // 存储到 function 对象
    std::function<int(int, int)> func = lambda;
}
```

## 在模板元编程中的强大应用

### 结合 `decltype` 和 SFINAE

```
#include <iostream>
#include <type_traits>

template<typename T>
class Wrapper {
T value;
public:
Wrapper(T v) : value(v) {}

// 只有 T 支持 + 操作时才启用此方法
auto add(const T& other) -> decltype(value + other) {
    return value + other;
}

// 替代方案：使用 SFINAE 禁用整个函数
template<typename U = T>
auto multiply(const U& other) -> std::enable_if_t<
std::is_arithmetic_v<U>, U> {
    return value * other;
}
};

int main() {
    Wrapper<int> w1(10);
    auto result1 = w1.add(5);        // 15
    auto result2 = w1.multiply(3);   // 30

    Wrapper<std::string> w2("hello");
    auto result3 = w2.add(" world"); // "hello world"
    // auto result4 = w2.multiply(3); // 编译错误：没有匹配的函数
}
```

### 处理依赖作用域的返回类型

```
#include <vector>

template<typename T>
class Container {
std::vector<T> data;
public:
// 返回类型依赖 Container<T>::iterator
auto begin() -> typename std::vector<T>::iterator {
    return data.begin();
}

auto end() -> typename std::vector<T>::iterator {
    return data.end();
}

// 更简洁的写法（C++14 起）
auto size() const {
    return data.size();
}
};
```

## 与 `auto` 返回类型的区别

C++14 引入了更简单的 `auto` 返回类型：

```
// C++14: 更简洁，但有限制
auto deduceReturnType() {
    return 42;  // 返回类型推导为 int
}

// C++11: 尾随返回类型，更灵活
auto flexibleReturnType() -> decltype(42) {
    return 42;
}
```

**关键区别**：

- `**auto**` **推导**：根据 return 语句推导类型
- **尾随返回类型**：明确指定或使用 `decltype` 表达式计算类型

## 总结

尾随返回类型机制提供了：

1. **更好的可读性** 对于复杂返回类型
2. **依赖参数的返回类型** 声明能力
3. **SFINAE 友好** 的语法结构
4. **统一的函数声明风格** 与 lambda 表达式一致
