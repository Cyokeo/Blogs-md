#### 题意
[宝石项链](https://mp.weixin.qq.com/s/Pu_WwuWSVvtzcDDLIdm3RQ)
小明正在欣赏他的一串宝石项链，这个项链还没有封口，是一条链，初始时从左到右宝石分别编号1,2,3,..., n。然而经过一段时间端详，小明觉得他应该把某颗宝石取下，然后放到某颗宝石的前面或者后面去。小明在正式进行调整前，想请你帮他模拟一下他的若干次调整，希望你能告诉他经过他若干次调整后宝石项链的样子。

#### 输入描述

第一行2个空格隔开的整数`n`和`q`，表示宝石数量和操作次数。

第二行3xq个空格隔开的整数，对第i次操作，表示将编号为的宝石取下，放到编号为的宝石旁边，当时放到其前，否则放到其后。

#### **思路与代码**

用两个数组分别记录每个编号的左边编号和右边编号，模拟双链表。调整宝石时更新这两个数组即可，最后找到头结点，根据记录右编号的数组依次向后遍历输出答案即可。

```cpp
n, q = map(int, input().split())  
ops = list(map(int, input().split()))  # ops的大小应该是q的三倍  
  
# 初始化每个元素的前后元素  
pre = [-1] * (n + 1)  
nxt = [-1] * (n + 1)  
  
for i in range(1, n + 1):  
    pre[i] = i - 1  # 1的左边为0  
    nxt[i] = i + 1  # n的右边为n+1  
      
for cnt in range(q):  
    id1 = ops[0 + 3 * cnt]  
    id2 = ops[1 + 3 * cnt]  
    pos = ops[2 + 3 * cnt]  
    # 把id1移除  
    if pre[id1] != 0:  
        nxt[pre[id1]] = nxt[id1]  
    if nxt[id1] != n + 1:  
        pre[nxt[id1]] = pre[id1]  
  
    # 把id1放到id2的前面或者后面  
    if pos == 0:  # 放到前面  
        nxt[id1] = id2  
        pre[id1] = pre[id2]  
        if pre[id2] != 0:  
            nxt[pre[id2]] = id1  
        pre[id2] = id1  
    else:  # 放到后面  
        pre[id1] = id2  
        nxt[id1] = nxt[id2]  
        if nxt[id2] != n + 1:  
            pre[nxt[id2]] = id1  
        nxt[id2] = id1  
  
# pre[i]为0的是当前的头结点  
head = -1  
for i in range(1, n + 1):  
    if pre[i] == 0:  
        head = i  
        break  
  
res = []  
while head != n + 1:  
    res.append(head)  
    head = nxt[head]  
print(' '.join(map(str, res)))
```
