# 元组结构体
## 一、先理解：什么是元组结构体？

```rust
pub struct UdpSocket(net_imp::UdpSocket);
```

这是 Rust 中的**元组结构体**（Tuple Struct），它的特点是：
- 字段没有名字，只有**位置索引**（从 0 开始）；
- 这里 `UdpSocket` 是一个「新类型包装器（Newtype Wrapper）」，里面只装了一个 `net_imp::UdpSocket` 类型的字段。

### 对比普通结构体和元组结构体

|类型|定义方式|字段访问方式|
|---|---|---|
|普通结构体|`struct S { field: T }`|`s.field`|
|元组结构体|`struct S(T);`|`s.0`|
