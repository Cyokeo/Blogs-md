2. 时钟同步.
	LinuxPTP指令：./ptp4l -i pfe0 -f configs/automotive-slave.cfg -H -m
	sudo ./ptp4l -i eth0 -f configs/automotive-master.cfg -m
	PTP同步：当计算的Pdelay过大时，应该舍弃该值，采用用卡尔曼滤波的估计值代替，从而提高同步精度。
	当用ptp4l完成硬件时钟之间的同步后，在每个端节点需要调用phc2sys将系统时钟与硬件时钟进行同步
	:./phc2sys -s pfe0 -m -f configs/automotive-slave.cfg -c CLOCK_REALTIME -O 0
	查看系统时钟与硬件时钟的差值：
		sudo ./phc_ctl /dev/ptp0 cmp
		sudo ./phc_ctl /dev/ptp3 cmp
	注意：phc2sys运行时也需要指定与ptp4l相同的配置文件，还需要注意系统时钟使用的UTC，而硬件时钟采用的世界原子时，它们之间的差距在配置文件中为utc_offset，默认值是37秒。
	将配置文件中utc_offset一项的值设为0，就可以消除utc与世界原子时之间的偏差。因为交换机上的时钟与硬件时钟保持一致，所以需要将系统时钟与硬件时钟保持一致。
	CNC运行在ubuntu上，ubuntu使用linuxptp的软件时间戳模式进行时钟同步，从而实现baseTime的统一基准。
