# 能力指针 - capptr_t
基于某个根能力的索引，索引到该能力空间中的某个具体slot「cte_t」。
```c
typedef struct cte {
	cap_t cap;
	mdb_node_t cteMDBNode;
} cte_t
```

# 能力空间 cspace与根能力cap_t

# 能力 - cap_t
用于索引到内核中的具体能力对象，访问权限、类型特有的元数据
```c
struct cap {
	uint64_t words[2];
};
typedef struct cap cap_t;
```

# 能力表项
维护该能力的派生关系元数据（mdb_node_t），支撑 CDT（能力推导树）的实现，完成权限撤销、内存安全复用等核心功能。
```c
typedef struct cte {
	cap_t cap;
	mdb_node_t cteMDBNode;
} cte_t
```
`mdb_node_t`（Metadata Database Node，元数据库节点）是 seL4 实现 CDT（能力推导树）的核心，**概念上的 CDT 树，在实现上就是通过所有 CTE 的 MDB 节点组成的双向链表**。
