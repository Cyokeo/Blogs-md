
## 服务端
> $ deskflow-server -c /etc/deskflow-server.conf
> 配置文件内容：
	section: screens
	    primary:
	    secondary:
	end
	section: links
	    primary:
	        right = secondary
	    secondary:
	        left = primary
	end
	section: options
	    tlsCertFile = /etc/deskflow.crt
	    tlsKeyFile  = /etc/deskflow.key
	end

## 客户端
>```
$ deskflow-client -f /etc/deskflow-client.conf
	文件内容：
	server = 192.168.1.100
	enableTLS = true
	tlsCertFile = /etc/deskflow.crt
```
